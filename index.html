    How it works

    1. Your master phrase and the website name are mixed together with a one-way scrambler (the same kind banks use). It's slow on purpose so hackers can't guess millions of phrases a second.
    2. The result is turned into a password using the characters and length you picked. Same inputs, same password, every time, on any device.
    3. Each website gets a totally different password. If one site leaks, the others are still safe, and nobody can work backwards to your master phrase.
    4. When a site needs a new password, raise its version from 1 to 2. You only need to remember which sites you bumped, and “Saved sites” can do that for you.

    Keep the settings in step 1 the same forever. Changing the length or characters changes every password. If one site has weird rules (like “no symbols”), change it just for that site and press “Remember this site's settings”.
